# notebook preview

Renders `notebook.md` (equations + figures) to HTML and PDF, serves it over HTTP
(Tailscale), and rebuilds automatically whenever `notebook.md` changes.

## URLs (phone / any Tailscale device)

- `http://100.101.197.82:8899/` — index page
- `http://100.101.197.82:8899/notebook.pdf` — newest PDF
- `http://100.101.197.82:8899/notebook.html` — live HTML

## How it stays up

A Windows scheduled task **NotebookPreview** runs at logon and is checked every 5
minutes. It launches `run_hidden.vbs` -> `run_forever.cmd`, which runs
`build.py --serve` and restarts it if it ever dies.

## Self-healing build

The loop does not rely on file-change events. Every 2 s it compares the mtime of
`notebook.md` with `notebook.pdf` and rebuilds whenever the source is newer, so a
missed edit, a crashed browser, a killed process or a reboot all recover on their
own. Failures back off 20 s and are logged to `build.log`.

## Manual use

```powershell
cd C:\Users\hjaca\research\chaos_llm_2026\notebook
python .preview\build.py            # one-off build
python .preview\build.py --serve    # build + serve + watch (foreground)
wscript .preview\run_hidden.vbs     # same, hidden, via the keep-alive loop
```

Task control:

```powershell
Start-ScheduledTask NotebookPreview     # start
Stop-ScheduledTask  NotebookPreview     # stop (also kill python if it lingers)
Get-ScheduledTask   NotebookPreview     # status
```

## Notes

- Math is rendered with a local offline KaTeX copy in `katex/` (no network, no LaTeX install).
- HTML/PDF are build artifacts and are git-ignored.
- PDF: A4, generated by headless Edge/Chrome with `--print-to-pdf`.
